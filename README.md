# JavaScript Projects 🚀

> A collection of 19 vanilla JavaScript projects built while
> mastering JavaScript from fundamentals to advanced patterns.
> Each project targets specific JS concepts — no frameworks used.
> Culminates in building a Mini React from scratch before
> entering the React ecosystem.

## 🎯 Goal
Master JavaScript deeply before entering React.
Every concept learned → immediately applied in a real project.
Understand WHY frameworks exist by feeling the pain without them
— then solving that pain yourself.

## 🗺️ Learning Path

\`\`\`
Tier 1 — Foundations     → feel the DOM pain
Tier 2 — Async & APIs    → real world data
Tier 3 — Adv. Patterns   → think like an engineer
Tier 4 — Boss Level      → build real software + your own React
Bonus   — Solidify        → lock in every concept
                ↓
            React 🚀
\`\`\`

## 🧠 JS Concepts Covered

### Fundamentals
- Variables, Scope, Closures
- Prototype chain & Inheritance
- Event loop — micro vs macrotasks
- this keyword — all 4 rules
- call, apply, bind

### Async
- Callbacks & Callback Hell
- Promises — chaining, combinators
- async/await
- Fetch API — deep dive
- AbortController

### OOP & Patterns
- Classes — extends, super, private fields
- Custom Error hierarchy
- Generators & Iterators
- Observer Pattern
- Builder Pattern
- Mixin Pattern
- Proxy & Reflect
- Symbols

### Browser & Performance
- DOM manipulation
- localStorage / sessionStorage
- Intersection Observer
- Debounce & Throttle
- Web Workers
- requestAnimationFrame
- Memory leak prevention
- Clipboard API
- History API

### Architecture
- State management patterns
- Module organization
- Virtual DOM & Diffing
- Component systems
- Hook implementations
